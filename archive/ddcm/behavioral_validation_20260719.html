§6 — Measurement vs Model: what was fixed vs what remains

F1–F4 (measurement asymmetries — fixed in this report)

  • F1 — CAR_PASS folding: simulated car-passenger trips were not folded into 'CAR' before comparison. Fixed: CAR_PASS→CAR on sim side everywhere. Net effect: sim CAR share was understated by ~30pp vs the folded figure.
  • F2 — Mode-share weighting: observed mode shares were time-weighted (per 15-min in-transit slot) while simulated were count-weighted (per trip leg). Fixed: both sides now count trips per leg.
  • F3 — TRAVEL in activity-share denominator: TRAVEL was in the observed denominator (5.1%) but not in the simulated denominator — inflated sim HOME/WORK shares. Fixed: TRAVEL excluded on both sides; reported separately as travel-share.
  • F4 — TRAVEL timing asymmetry: simulated TRAVEL timing was departure-time spikes (1 row per leg); observed was per-15-min in-transit occupancy. Fixed: sim TRAVEL legs expanded to per-slot occupancy before building timing distribution.
  • F6 — Activity-map silently dropped 'Other' (891 slots): old code had no mapping for 'Other' → slots dropped. Fixed: uses data_loader.ACTIVITY_MAP which maps 'Other' and 'Sightseeing' → LEISURE, consistent with how estimation loaded the data.

F0 — McFadden ρ² sample discipline (fixed)

The original ρ² = −0.864 was computed on a worker-only subset (3,025p) while θ̂ was the MLE on the full mixed sample (5,218p workers+non-workers). The MLE guarantee LL(θ̂) ≥ LL(0) only holds on the estimation sample. Additionally, LL(0) was computed on a separately rebuilt graph, risking state-index misalignment. Both are fixed: LL(θ̂) and LL(0) now use all 7390 persons + the same graph-state indices (recompute_graph_utilities on the existing graph object, not rebuild).

F5 — Genuine model misfit (structural): activity shares

After all F1–F4 fixes, a gap remains: simulated WORK time share ≈21.0% vs observed 21.7% (-0.8pp gap). This is not a measurement artifact — it is a structural property of the K=10 "Option A" specification:

  • No activity alternative-specific constants (ASCs) — Västberg (2020) §4.4 explicitly estimates these (activity ASCs, tour ASCs, trip ASCs) specifically to force the simulated marginal distributions (trips/day, mode split, work share) to match observed. Our K=10 spec fixes the mode ASCs at HH MNL estimates and has no activity ASCs.
  • A model without activity constants has no mechanism to match activity-time-share marginals. Any residual gap is therefore expected and not attributable to a code bug.
  • The schedule pull δ=0.03814/min is the only force directing workers toward WORK; β₀_leis=0.000 and β₀_shop=0.000 make discretionary activities less attractive than HOME; θ_travel=0.221 halves commute disutility; logit noise competes against δ at every step.

F5b — Genuine model misfit (structural): transit collapse

Simulated transit mode share ≈ 0% vs observed ≈ 3.4% (BUS + TRAIN). This is not a code bug or OD-data gap; it is a quantified consequence of the K=10 spec. Diagnostic run estimation/experiments/mode_collapse_diagnostic.py establishes the following:

  • TRAIN: 99.6% of OD pairs have TT=0 (no service) — Higashihiroshima has very limited rail coverage. TRAIN is structurally infeasible for virtually all trips.
  • BUS: 99.4% feasible but utility is always negative — ASC=0 means the travel time penalty is never offset by a mode preference. BUS is only chosen when the destination activity is worth at least +0.81 utiles/step extra — exceeding the WORK schedule pull (δ=0.015/min × 15 min = 0.23/step).
  • CAR has a permanent +1.124 advantage over PT after θ_travel scaling. To make BUS competitive with CAR requires ASC_pt_adj ≈ +1.35 utiles (≈ +3.32 in raw K=11 units). This is the parameter retired in Option A.

The "θ_travel lifts PT share" claim in the code comment is directionally correct — at θ_travel=1.0 (full MNL), CAR ASC=2.756; at θ_travel=0.408 it is 1.124 — but the absolute PT share remains near zero because BUS still starts at 0 and has negative total utility on median trips.

Decision implication (mode): matching the observed 3.4% transit share requires at minimum a free PT constant (one extra param, "Option B" / K=11 lite) or full activity/mode ASC estimation (Västberg §4.4). See §7.

Decision implication (activity shares): to match activity-time-share marginals, the model spec needs activity-/tour-/trip-level ASCs estimated jointly with the DP parameters. That is a model-spec change; it is not in scope of this validation.

§7 — Caveats and scope

  • Mode spec options: to improve the transit / mode-share fit, three options exist: A) document as known K=10 Option A limitation (current); B) add a single free PT constant (ASC_pt_adj ≈ +3.32 in MNL units) — makes K=11, no re-derivation of gradient; C) estimate full activity/mode/tour ASCs jointly with DP parameters (Västberg 2020 §4.4). Options B and C require a re-estimation run; they are not in scope of this validation.
  • ρ² discipline: ρ² = 1 − LL(θ̂)/LL(0) is evaluated on the same 7390-person mixed sample as estimation, using the same graph-state indices. LL(0) sets the 8 estimated params to 0; fixed HH MNL mode constants (ASC, β_time, β_cost) are unchanged. ρ² is valid (the MLE guarantee LL(θ̂) ≥ LL(0) holds on this sample).
  • Same-subsample discipline: observed behavioral stats (§1–§4) are restricted to the 3120 worker persons only, since the behavioral figures (work timing, trip counts) only make sense for workers with a schedule. ρ² and LL use all 7390 persons. Motorcycle/Taxi persons and persons with unmodelled mandatory activities (Hospital, CHILD_DROPOFF) are excluded.
  • 'Other' activity mapping: 'Other' and 'Sightseeing' observed slots (n_dropped_act_slots from disabled Hospital/Pickup) are mapped to LEISURE via data_loader.ACTIVITY_MAP, consistent with how the estimation loaded the data. Disabled-activity slots are excluded.
  • 15-min step coarseness: simulated trip durations are multiples of 15 min. Observed durations are exact (minute-level). Lower-end trip-length distributions differ by construction.
  • Observed trip length: obs_trip_len uses the 3120-worker subset (same as simulation).
  • Tour segmentation: observed tours from trip_data_higashihiroshima.csv (purpose='Home' splits tours); simulated tours from TRAVEL/HOME alternation. Small definitional gap.
  • In-sample only: this validates the same persons used for estimation. Out-of-sample validation requires a held-out subsample.
  • car_owned grouping: non-owner persons are assigned CAR-excluded graphs (matching estimation); CAR_PASS is available as a mode to passengers even in non-owner groups (passenger of someone else's car), and is folded into CAR for comparison.
